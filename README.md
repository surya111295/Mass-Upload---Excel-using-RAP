# Mass-Upload---Excel-using-RAP
Mass Upload Data from Excel Sheet into RAP Application

In this Demo We see the Upload of the Excel Data into RAP 

Features : Cloud Compliant,
           100% Clean-Core,
           Fully RAP managed - No UI5 Workaround,
           Mass Upload

Scenario : A database table created ZSUPPLIERMASTER with Supplier Details, The records should be updated from an excel file.



Technique Used : RAP - Managed Scenario,
                 ODATA V4,
                 Abstract Entity with Association
